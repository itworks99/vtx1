== Overview

=== What VTX1 is

VTX1 is a balanced-ternary System-on-Chip: binary on the outside,
ternary on the inside. Buses, memories, files and I/O carry trits in a
2-bit hardware encoding; the instruction set, registers, arithmetic and
addressing are native balanced ternary (trits −1, 0, +1; 18-trit machine
words). The project's thesis is that a three-valued, symmetric number
system buys measurable architectural properties - and the project's
method is to measure them honestly, with matched controls, at every
level from instruction counts down to SPICE.

=== Design principles (as practiced)

* *Trit-native, not trit-themed.* The ISA, immediates, branch offsets
  and the entire datapath are balanced ternary. The only trit-to-binary
  conversion in the CPU is at the memory address pins. Binary
  instruction encodings were rejected as a deficiency and removed.
* *One source of truth.* The complete ISA lives in
  `src/assembler/isa/isa.go`. The Verilog opcode constants and decode
  tables are generated from it, so the assembler, simulator and RTL
  cannot drift apart.
* *No microcode.* Operations are single-cycle hardwired logic or
  dedicated multi-cycle units (the iterative divider). The microcode
  layer of the original design was retired.
* *Cross-checked at every seam.* The same binary runs in the ISA
  simulator and on the RTL, and retired-instruction counts must match
  exactly. Benchmark results are asserted by tests on both sides of
  every comparison.
* *Evaluation by simulation tiers, not FPGA.* An FPGA cannot be ternary,
  so the architecture is evaluated where the substrate cannot distort
  it: instruction-level (Tier A), cycle-level RTL against matched
  binary controls, gate-level synthesis, and SPICE on production
  Sky130 device models (Tier B).

=== The number system

Balanced ternary with 18-trit words gives a symmetric value range of
±(3^18^−1)/2 = ±193,710,244 and these properties, all exploited by the
hardware:

* Negation is tritwise (swap −1 and +1): subtraction is addition, and
  NOT and NEG are the same operation.
* There is no sign bit and no two's-complement asymmetry; "unsigned"
  does not exist.
* Zero-trit padding preserves any value - no sign extension exists.
* Truncation rounds to nearest; the iterative divider naturally produces
  round-to-nearest quotients.
* Dropped adder carries implement arithmetic mod 3^18^; a nonzero final
  carry trit is the true sign of an overflowed difference, which gives
  overflow-correct three-way compare for free.
* Multiplier digits are already in {−1, 0, +1}: multiplication is
  natively Booth-recoded.

=== Physical trit encoding

Each trit is stored as 2 bits: `00` = −1, `01` = 0, `10` = +1, `11` =
undefined (an instruction containing it traps). An 18-trit word occupies
36 bits; files store words as 5 bytes. Tier B (SPICE on Sky130) showed
this encoding is not a stopgap: at the gate level it is cheaper than
voltage-mode ternary CMOS, so the binary-encoded trit datapath is the
deliberate engineering choice (see the Evaluation chapter).
