== Memory System

Memory is word-addressed: one address names one 18-trit word (36 bits in
the 2-bit encoding; 5 bytes in files). A scalar instruction advances the
PC by 1, a VLIW bundle by 3. Positive addresses are memory; negative
addresses are memory-mapped I/O.

=== Tightly-coupled instruction memory (TCM)

`src/memory/vtx1_tcm.v` serves the core's dedicated fetch port with a
single-cycle synchronous read of *three consecutive words* (the issue
group), covering the program region 0x1000-0x1FFF (4096 words). The
array is interleaved across four banks on the low address bits, so any
three consecutive addresses - arbitrary alignment, branch targets
included - read in one cycle. Its write port snoops the CPU's store
path (write-through), which keeps CPU-originated writes coherent and
doubles as the boot-time load path: the boot flow loads code with
ordinary stores. Writes by other bus masters are not snooped.

=== Data scratchpad

`src/memory/vtx1_scratchpad.v` sits between the core's memory port and
the SoC bus master port, covering the low 16K words. In-window *reads*
are served from a local synchronous RAM with a one-cycle handshake
instead of the multi-cycle bus matrix round trip. *Writes* always pass
through to the bus - external memory remains the source of truth for
DMA, debug and verification - and are snooped into the local copy.
Out-of-window accesses (including all MMIO) pass through untouched.

The scratchpad also exposes a second read port and a shared write port
to the MAC accelerator's DMA engine (CPU snoop writes have priority).
Ownership caveat, stated: words the accelerator writes exist only in the
scratchpad until a CPU store overwrites that address.

=== Bus and main memory

The core's bus port is master 0 on the bus matrix
(`src/system/bus_matrix.v`), alongside the DMA and debug controllers.
The matrix routes the MMIO window to the peripheral router and
everything else to the memory controller
(`src/memory/memory_controller.v`), which fronts the cache controller
and the external SRAM pins. The SoC testbench models a 16K-word external
SRAM on those pins; hello_world and all benchmark programs execute
through this full path.

=== Cache

`src/cache/cache_controller.v` implements direct-mapped instruction and
data caches (64 entries each). The data and tag arrays are written in a
reset-free synchronous block so synthesis infers RAMs; only the valid
and dirty bits are registers. With the TCM and scratchpad carrying the
hot paths, the cache is not performance-critical in the current memory
map.
