= VTX1 Trit-Native Instruction Encoding
:toc: left
:icons: font

== Overview

VTX1 is a balanced-ternary VLIW machine. Every operation is encoded in one
18-trit machine word; a VLIW instruction is a bundle of 3 operation words
(54 trits = 108 bits in the 2-bit-per-trit hardware encoding, matching
`VLIW_WIDTH`).

The single source of truth for this encoding is `src/assembler/isa/isa.go`.
The Verilog constants in `src/common/vtx1_isa_generated.vh` are generated
from it (`cd src/assembler && go run ./isa/gen`) so the toolchain and the RTL
cannot drift apart.

== Physical representation

Each trit is stored as 2 bits (hardware encoding, see
`src/common/ternary_constants.v`):

[cols="1,1,1"]
|===
| Trit | Encoding | Meaning

| -1 | `00` | negative
|  0 | `01` | zero
| +1 | `10` | positive
|  - | `11` | undefined/invalid
|===

An 18-trit word therefore occupies 36 bits, stored in files as 5 bytes with
4 zero padding bits. Trit `t` (0 = most significant) occupies bits
`[35-2t : 34-2t]` of the word.

== Operation word layout

All formats start with a 4-trit opcode (trits 0..3). The opcode space holds
81 values -- exactly 3^4 -- and the VTX1 instruction set fills it completely.
The all-zero-trit word is NOP.

[cols="1,3"]
|===
| Format | Layout (trit positions, MSB first)

| R3     | rd 4..6 \| rs1 7..9 \| mode 10 \| payload 11..17 +
           mode 0: rs2 = trits 15..17; mode +1: 7-trit immediate (±1093)
| R2     | rd 4..6 \| rs 7..9
| R1     | r 4..6
| None   | (all operand trits zero)
| Mem    | reg 4..6 \| mode 7 \| payload 8..17 +
           mode 0: 10-trit direct address/immediate (±29524) +
           mode +1: base 8..10, index 11..13 (`[base]` uses index TZ) +
           mode -1: base 8..10, 7-trit offset 11..17
| Branch | rs1 4..6 \| rs2 7..9 \| 8-trit PC-relative word offset 10..17
           (±3280); rs2 = TZ encodes "compare against zero"
| Jump   | 14-trit absolute word address, trits 4..17 (±2391484)
|===

Because every numeric field is balanced ternary, immediates, offsets and
branch displacements are naturally signed and symmetric around zero -- there
is no sign bit and no two's-complement asymmetry. Negative absolute addresses
are architecturally legal and reserved for memory-mapped I/O.

== Addressing

Memory is word-addressed: one address names one 18-trit word. A scalar
instruction advances the PC by 1, a VLIW bundle by 3. Data directives
(.DB/.DW/.DT) emit one word per item; strings emit one word per character.

== Registers

Registers live in a unified 3-trit index space (pattern = balanced(index-13)):

[cols="1,1,3"]
|===
| Registers | Indices | Role

| T0-T6 | 0-6   | general purpose
| TB    | 7     | base pointer
| TA    | 8     | accumulator
| TC    | 9     | program counter
| TS    | 10    | status
| TI    | 11    | instruction
| VA, VT, VB | 12-14 | vector
| FA, FT, FB | 15-17 | floating point
| TZ    | 18    | zero register: reads 0, writes discarded
|===

== VLIW packing rules

The assembler enforces, per bundle:

1. Maximum of 3 operations (shorter bundles are NOP-padded)
2. Maximum of 1 memory operation
3. Maximum of 1 control operation
4. No two operations may write the same register (error)
5. An operation reading a register that another slot writes sees the
   pre-bundle value; the assembler emits a hazard warning

== Assembler representation

[source,assembly]
----
[ADD T0, T0, 1] [ADD T1, T1, 1] [ADD T2, T2, 1]
----

== Example

`BEQ T3, 0, done` four words before `done` encodes as: opcode BEQ
(value 30, pattern `0-0-`), rs1 = T3 (`-0-`), rs2 = TZ (`+--`, compare
against zero), offset +4 (`000000++`) -- in trits: `0-0--0-+--000000++`.
